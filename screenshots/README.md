# Screenshots

Place screenshots from your actual Kali Linux lab session in this directory.

## Naming Convention

Use sequential, descriptive names:

```text
01-user-created.png
02-whoami-student01.png
03-project-directories.png
04-report-created.png
05-hidden-file-visible.png
06-report-edited.png
07-report-copied.png
08-classified-file.png
09-install-script.png
10-install-permissions.png
11-classified-permissions.png
12-admin-notes-permissions.png
13-cleanup.png
14-backup-created.png
15-final-tree-and-permissions.png
16-command-history.png
```

You do not have to use every filename if one screenshot clearly covers multiple checklist items.

## Quality Guidelines
- Use PNG where practical.
- Keep terminal text readable.
- Capture enough context to identify the command and result.
- Do not rename screenshots after documenting them in `EVIDENCE_CHECKLIST.md` unless you update the checklist.
