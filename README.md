# Linux Command Line Practical Task

## Overview
This project documents the **Linux Command Line Practical Task** performed as the newly created Kali Linux user `student01`.

The lab focuses on basic Linux user management, directory and file management, text editing, file movement and copying, permissions with `chmod`, cleanup, backups, and final verification.

> **Important:** This repository is a documentation/template package. It does not claim that the lab has been completed. Add your actual screenshots, command output, and lab-generated files as you perform the tasks.

## Lab Objectives
- Create and switch to a new Linux user.
- Work with directories and files from the user's home directory.
- Edit, copy, move, rename, and create files.
- Apply Linux file permissions with `chmod`.
- Create a backup of selected project contents.
- Verify the final structure and permissions.
- Optionally record the command history.
